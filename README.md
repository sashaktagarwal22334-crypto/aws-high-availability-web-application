# AWS Cloud Portfolio

## Project Overview
This project demonstrates my practical learning and implementation of three core Amazon Web Services (AWS) services: Amazon VPC, AWS IAM, and Amazon S3.

The objective is to understand cloud networking, identity and access management, and secure object storage through hands-on AWS Console configuration.

## AWS Services Implemented

### 1. Amazon VPC
- Created a custom Virtual Private Cloud.
- Configured IP address ranges using CIDR.
- Explored public subnet configuration.
- Configured Internet Gateway and routing.

### 2. AWS IAM
- Created an IAM role for AWS resource access.
- Explored IAM policies and permissions.
- Applied the principle of least privilege.
- Configured controlled access to S3 resources.

### 3. Amazon S3
- Created an S3 bucket.
- Configured private bucket access.
- Enabled bucket versioning.
- Configured server-side encryption.
- Organized objects using folders.
- Uploaded sample files.
